# manim-web 架构设计

> 版本：2.0 | 核心设计：单进程直接操作 manim

---

## 一、系统架构

```
┌─────────────────────────────────────────────────────┐
│                    AI 助手 (LLM)                      │
│                  调用 MCP 工具                        │
└──────────────────────┬──────────────────────────────┘
                       │ MCP (stdio)
                       ▼
┌─────────────────────────────────────────────────────┐
│             mcp/server.py + mcp/tools.py              │
│           16 个 web_persistent_* 工具                 │
│        _ensure_session → 自动初始化 + 看门狗           │
└──────────────────────┬──────────────────────────────┘
                       │ 方法调用 (同进程)
                       ▼
┌─────────────────────────────────────────────────────┐
│           DirectManimSession (Facade)                 │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌─────────┐│
│  │ core/     │ │animation/│ │ render/  │ │preview/ ││
│  │lifecycle  │ │mobject   │ │frame     │ │server   ││
│  │executor   │ │play      │ │video     │ │websocket││
│  │watchdog   │ │builder   │ │capture   │ │         ││
│  └──────────┘ └──────────┘ └──────────┘ └─────────┘│
└──────────────────────┬──────────────────────────────┘
                       │ 直接操作
                       ▼
┌─────────────────────────────────────────────────────┐
│              manim (Cairo/OpenGL 渲染器)               │
│           Scene → Animation → Frame → WebSocket      │
└─────────────────────────────────────────────────────┘
```

**核心设计**：无 TCP/WebSocket 服务端中间层，单进程内直接操作 manim Scene 对象。

## 三、核心流程

### 3.1 初始化流程

```
web_persistent_start(project="demo")
    │
    ├─ 已有会话? → ensure_preview_visible() → 返回状态
    │
    └─ 新会话:
        ├─ reset_session() → 创建 DirectManimSession
        │   └─ 有保存状态? → 设置 _pending_restore
        ├─ init_scene() → 创建 Scene, 设置帧回调, 优化渲染
        ├─ start_preview() → 启动 WebSocket 服务器, 打开浏览器
        └─ restore_after_preview() → 等待 ws_clients → 恢复代码
```

### 3.2 动画播放流程

```
web_persistent_play(anim_class="Create", targets="c")
    │
    ├─ _animating = True, _anim_frame_index = 0
    ├─ executor.submit(play_anim)  (Cairo 模式在线程池执行)
    │   │
    │   ├─ 解析动画类和目标图形
    │   ├─ 双目标动画? → Transform(c, s)
    │   ├─ 单目标? → Create(c)
    │   └─ self.play(anim) → manim 渲染
    │       │
    │       └─ 每帧: update_frame() → frame_callback()
    │           │
    │           └─ on_renderer_frame():
    │               ├─ 首帧? → 重置 _anim_start_time
    │               ├─ 节拍控制: sleep_time = expected - elapsed
    │               └─ cache_frame() → WebSocket 推送
    │
    ├─ _render_frame() → 渲染最终帧
    ├─ 记录代码: self.play(Create(c))
    ├─ save_state() → 持久化到 state.json
    └─ _animating = False
```

### 3.3 帧推送机制

```
manim 渲染循环
    │
    └─ update_frame(scene, moving_mobjects)
        │
        ├─ camera.capture_mobjects() → 渲染到帧缓冲
        └─ frame_callback(frame)
            │
            └─ on_renderer_frame(session, frame)
                │
                ├─ preprocess_frame() → 去 alpha, 转 uint8
                ├─ 节拍控制 (动画期间):
                │   ├─ _anim_frame_index += 1
                │   ├─ 首帧重置 _anim_start_time
                │   ├─ sleep_time = (index/fps) - elapsed
                │   └─ sleep(sleep_time) if > 0
                └─ cache_frame() → 编码 + WebSocket 广播
```

### 3.4 会话持久化

```
save_state()
    │
    └─ state.json = {
        "project": "demo",
        "accumulated_lines": ["c = Circle(...)", "self.add(c)", "self.play(Create(c))"],
        "persistent_env_keys": ["c"],
        "config": {
            "quality": "medium",
            "renderer": "cairo",
            "frame_rate": 1
        },
        "preview_port": 8765
    }

restore_after_preview()
    │
    ├─ 等待 ws_clients 连接 (最多 2 秒)
    └─ 逐行执行 accumulated_lines
        ├─ 静态操作 → scene.add() → 渲染帧
        └─ 动画操作 → self.play() → 帧推送
```

## 四、关键设计决策

### 4.1 单进程直接操作

不使用 TCP/WebSocket 服务端中间层，AI 通过 MCP 调用直接操作同进程内的 manim Scene 对象。

**优势**：零延迟、无序列化开销、简化部署。

### 4.2 帧回调优化

覆盖 `renderer.render()` 为 `_optimized_render()`，跳过文件写入（`_push_frame = pass`），仅触发 `update_frame()` + `frame_callback()`。

### 4.3 动画节拍控制

- `_frame_rate = 1`：每帧都触发回调
- `_target_fps = config.frame_rate`：按 manim 原生帧率推送
- 首帧重置 `_anim_start_time`：消除 executor 提交延迟

### 4.4 延迟恢复

`_pending_restore` 机制：先启动预览再恢复代码，确保浏览器 WebSocket 连接后再播放动画。

### 4.5 看门狗恢复

`_ensure_healthy()` 检测会话异常后自动重建（最多 3 次），使用 `_soft_close()` 保留预览/终端/日志。

## 六、WebSocket 帧协议

帧数据以二进制消息推送：

```
[0x01] [mime_len] [mime_bytes] [frame_data]
```

- `0x01` — 帧类型标识
- `mime_len` — MIME 类型长度（1 字节）
- `mime_bytes` — MIME 类型（如 `image/webp`）
- `frame_data` — 编码后的帧数据（WebP/JPEG）
