# manim-web 常见问题

> 故障排查 + 沙箱说明

---

## 一、会话与初始化

### Q: `Session not initialized` 错误

**原因**：未调用 `web_persistent_start`。

**解决**：先调用 `web_persistent_start(project="xxx")` 初始化会话。

### Q: `already_running: true` 是错误吗？

不是。表示会话已在运行，直接使用 `add`/`play` 等工具即可。

### Q: 浏览器没打开

**检查**：
1. `start` 返回的 `preview_url` 是否可访问
2. 查看终端日志是否有端口冲突
3. 手动打开 `http://127.0.0.1:{port}/preview`

### Q: 会话自动恢复

v2.0 看门狗机制：`_ensure_healthy` 检测到会话异常后自动重建（最多 3 次），无需手动干预。

### Q: 跨对话恢复

关闭终端+浏览器后重启 MCP，`web_persistent_start` 会从 `state.json` 自动恢复场景代码。`restored_lines` 表示恢复的行数。

## 二、动画与渲染

### Q: 图形直接出现没有动画

`add_mobject` 是**静态添加**，图形瞬间出现。需要动画效果请用 `play`：

| 操作 | 效果 |
|------|------|
| `mobject` → 静态添加 | 瞬间出现 |
| `play(Create(c))` | 描边动画出现 |
| `play(FadeIn(c))` | 淡入出现 |
| `play(GrowFromCenter(c))` | 从中心生长 |

### Q: 动画帧率异常

manim-web 使用 manim 原生帧率（默认 60fps）。帧数 = run_time × frame_rate，例如 1 秒动画 = 60 帧。

### Q: 浏览器动画不同步

确保浏览器和终端同时打开。恢复场景时，`restore_after_preview` 会等待 WebSocket 连接后再播放动画。

### Q: Transform 报错

Transform 类动画需要两个目标：`targets="source,target"`。支持的类：Transform, ReplacementTransform, TransformFromCopy, ClockwiseTransform, CounterclockwiseTransform, CyclicReplace, Swap。

## 三、导出与视频

### Q: 导出代码缺少 self.add()

v2.0.1 已修复：`add_mobject` 现在同时记录 `c = Circle(...)` 和 `self.add(c)`。

### Q: render_video 失败

**检查**：
1. ffmpeg 是否安装：`ffmpeg -version`
2. 导出代码是否有效：先 `export` 查看代码
3. LaTeX 公式需要 TeX Live

### Q: 导出代码有 self.remove()

使用 `export(clean=true)` 过滤掉 `self.remove()` 和注释行。

## 四、沙箱级别

### 总览

| 能力 | strict | relaxed | full |
|------|--------|---------|------|
| manim 全部 API | ✅ | ✅ | ✅ |
| 数学工具（numpy/math/sympy） | ✅ | ✅ | ✅ |
| self / scene 引用 | ✅ | ✅ | ✅ |
| print() 输出 | ✅ | ✅ | ✅ |
| 文件读取 open() | ❌ | ✅ 仅项目目录 | ✅ 任意路径 |
| import 模块 | ❌ | ✅ 白名单 20 个 | ✅ 任意模块 |
| exec / eval / compile | ❌ | ❌ | ✅ |
| os / sys / subprocess | ❌ | ❌ | ✅ |

### strict（默认）

适合绝大多数动画制作。AI 生成的代码不需要文件操作。

**可用**：manim API、numpy、math、sympy、random、itertools、print

**不可用**：open、import、exec、eval、compile、os、sys

### relaxed

需要读取项目目录文件或导入白名单模块时使用。

**白名单模块**：json, re, os.path, pathlib, csv, datetime, io, copy, dataclasses, typing, math, cmath, collections, itertools, functools, operator, decimal, fractions, statistics, random

**文件操作**：仅限项目目录内读取

### full

完全信任 AI 生成代码，无任何限制。危险操作需 `force=true` 确认。

## 五、错误信息速查

| 错误 | 原因 | 解决 |
|------|------|------|
| `Session not initialized` | 未 start | 先调 `web_persistent_start` |
| `Animation in progress` | 上一个动画未完成 | 等待完成后再操作 |
| `dangerous: true` | full 模式检测到危险操作 | 确认安全后设 `force=true` |
| `Sandbox restriction: xxx() is not allowed` | strict/relaxed 模式调用被阻止的内置函数 | 切换到更宽松的沙箱级别或用 manim API 替代 |
| `name 'xxx' is not defined` | strict 模式缺少该名称 | 切换到 relaxed/full 或用 manim API |
| `ffmpeg not found` | 未安装 ffmpeg | 安装 ffmpeg 并加入 PATH |
| `ws_clients: 0` | 浏览器未连接 | 刷新浏览器或重新 start |

## 六、性能优化

### 渲染质量选择

| 场景 | 推荐质量 |
|------|---------|
| 快速预览/调试 | medium (1280×720) |
| 最终输出 | high (1920×1080) |
| 高分辨率需求 | 4k (3840×2160) |

### 动画时长建议

- 简单动画（Create/FadeIn）：0.5-1 秒
- 复杂动画（Transform/Write）：1-2 秒
- 组合动画：按内容调整，总时长不超过 10 秒
