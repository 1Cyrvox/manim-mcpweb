🚀 特性

为什么选 manim-web

AI 驱动 · 浏览器实时预览 · 会话持久化 · 沙箱安全

🤖

AI 驱动 · MCP 协议

基于 Model Context Protocol 标准，与 Claude、Cursor、Windsurf 等 AI 客户端无缝集成。说一句话，AI 帮你写 manim 代码并渲染。

👁️

浏览器实时预览

WebSocket 实时推送渲染帧到浏览器，代码即预览，增量渲染秒级响应。告别 CLI 反复渲染的痛苦循环。

💾

会话跨对话保持

场景状态持久化到磁盘，AI 对话结束后场景不丢失。下次对话无缝续接，多项目并行互不干扰。

🔒

三级沙箱安全

strict / relaxed / full 三级代码执行策略，危险操作拦截。AI 生成代码安全可控，默认最安全模式。

📦

一键安装 · 内置 manim

pip install 一步到位，内置优化版 manim v0.20.2。无需单独安装 manim，依赖链自动处理。

🎬

多格式导出

支持 mp4 / gif / webm 视频导出，高质量截图捕获。从创作到分享一气呵成。

⚡ 上手

30 秒上手

三步开始创作 AI 动画

1

安装

确保 Python 3.12+ 已安装，然后：

pip install manim-web-mcp
2

启动

运行命令，浏览器自动打开预览页面：

manim-web-mcp
3

创作

在 AI 客户端中用 MCP 工具生成动画：

web_persistent_start(project="demo")
web_persistent_add(code="c = Circle(radius=1, color=BLUE)")
web_persistent_add(code="self.play(Create(c))")
🔧 工具

MCP 工具一览

16 个精心设计的 MCP 工具，覆盖动画创作全流程

🔥 核心

web_persistent_start启动项目 + 打开浏览器预览
web_persistent_add执行 manim 代码（最常用）
web_persistent_play快捷播放动画
web_persistent_mobject快捷创建图形

👁️ 预览

web_persistent_frame查看当前帧
web_persistent_capture高质量截图
web_persistent_render_video渲染 mp4 / gif / webm

⚙️ 管理

web_persistent_export导出 .py 文件
web_persistent_reset重置场景
web_persistent_status查询状态
web_persistent_list列出所有项目
web_persistent_stop停止会话
🛡️ 安全

沙箱安全

三级执行策略，AI 生成代码安全可控

strict
默认 · 最安全

禁止文件 I/O、import、exec

relaxed
需要读写文件时

仅项目目录 · 白名单 import

full
完全信任

全部权限 · 危险操作检测
