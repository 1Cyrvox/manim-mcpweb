## 1. web_persistent_start — 初始化项目

**必须第一个调用。** 创建 manim 场景、打开浏览器预览、恢复上次状态。

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| project | string | `"default"` | 项目名。传 `""` 按 caller 前缀自动生成 |
| orientation | string | `"landscape"` | 画面方向：landscape / portrait |
| quality | string | `"medium"` | 渲染质量：medium / high / 4k |
| renderer | string | `"cairo"` | 渲染器：cairo（推荐）/ opengl |
| sandbox | string | `"strict"` | 沙箱级别：strict / relaxed / full |
| caller | string | `"demo"` | 调用者标识，用于自动命名隔离 |
| show_terminal | bool | `true` | 是否打开终端窗口 |

**返回值**：
- `success` — 是否成功
- `already_running` — 是否复用已有会话
- `preview.preview_url` — 浏览器预览地址
- `restored_lines` — 恢复的代码行数（重启后自动恢复）
- `workspace.dir` — 工作区目录

**行为**：
1. 已有会话运行 → 重连，打开浏览器/终端
2. 无会话 → 创建新会话，初始化场景，启动预览
3. 有保存状态 → 浏览器连接后自动恢复代码（`restore_after_preview`）

|------|------|--------|------|
| project | string | `"default"` | 项目名 |

## 3. web_persistent_add — 执行代码

在 manim 场景中执行任意 Python 代码。支持 manim 全部 API。

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| code | string | **必填** | Python 代码 |
| project | string | `"default"` | 项目名 |
| force | bool | `false` | full 模式下强制执行危险操作 |

**示例**：
```
code = "t = Text('Hello', font_size=48)\nself.play(Write(t))"
```

**沙箱行为**：
- `strict` — 仅 manim API + 数学工具
- `relaxed` — 允许项目目录文件读取 + 白名单 import
- `full` — 无限制，危险操作需 `force=true`

## 4. web_persistent_play — 播放动画

对目标图形播放指定动画。

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| anim_class | string | **必填** | 动画类名：Create, FadeIn, FadeOut, Transform 等 |
| targets | string | `""` | 目标图形名，逗号分隔 |
| run_time | float | `1.0` | 动画时长（秒） |
| project | string | `"default"` | 项目名 |

**双目标动画**：Transform 类动画（Transform, ReplacementTransform, Swap 等）传入两个目标，自动映射为 `Transform(source, target)`。

**示例**：
```
anim_class = "Create", targets = "c"           → self.play(Create(c))
anim_class = "Transform", targets = "c,s"     → self.play(Transform(c, s))
anim_class = "FadeOut", targets = "c", run_time = 0.5
```

**返回值**：`success`, `elapsed`, `frames`, `fps`

## 5. web_persistent_mobject — 创建图形

创建并添加图形到场景。图形**瞬间出现**（静态添加），如需动画效果请用 `play`。

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| class_name | string | **必填** | 图形类名 |
| name | string | `""` | 变量名，空则自动生成 |
| args | list | `[]` | 位置参数 |
| kwargs | dict | `{}` | 关键字参数 |
| project | string | `"default"` | 项目名 |

**支持的图形**：Circle, Square, Rectangle, Triangle, Polygon, Star, Line, Arrow, Vector, Dot, Arc, Ellipse, Annulus, Sector, RegularPolygon, NumberLine, Axes, Sphere, Cube, Cone, Text, MathTex 等。

**示例**：
```
class_name = "Circle", name = "c", kwargs = {"radius": 1, "color": "RED"}
class_name = "Text", name = "t", kwargs = {"text": "Hello", "font_size": 48}
```

**导出代码**：生成 `c = Circle(...)` + `self.add(c)`

## 6. web_persistent_play_composite — 组合动画

播放组合动画（AnimationGroup, Succession, LaggedStart 等）。

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| animations | string | **必填** | JSON 数组，动画描述 |
| project | string | `"default"` | 项目名 |

**简单动画**：
```json
[{"type": "Write", "targets": ["t1"], "kwargs": {"run_time": 1.5}}]
```

**组合动画**：
```json
[{
  "type": "AnimationGroup",
  "children": [
    {"type": "FadeIn", "targets": ["c"]},
    {"type": "FadeIn", "targets": ["s"]}
  ],
  "kwargs": {"lag_ratio": 0.2}
}]
```

**支持的组合类**：AnimationGroup, Succession, LaggedStart, LaggedStartMap

## 9. web_persistent_export — 导出代码

导出累积的场景代码为 .py 文件，可直接用 manim 渲染。

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| scene_name | string | `"ExportedScene"` | 场景类名 |
| file_path | string | `""` | 保存路径，空则默认 |
| project | string | `"default"` | 项目名 |
| clean | bool | `true` | 过滤 self.remove() 和注释行 |

**导出格式**：
```python
from manim import *

class ExportedScene(Scene):
    def construct(self):
        c = Circle(color='RED', radius=1)
        self.add(c)
        self.play(Create(c))
```

## 典型工作流

```
1. start(project="demo")           → 初始化，浏览器打开
2. mobject(class_name="Circle"...) → 创建图形
3. play(anim_class="Create"...)    → 播放动画
4. play(anim_class="FadeOut"...)   → 淡出
5. export()                        → 导出代码
6. render_video(format="mp4")      → 渲染视频
```

## 跨对话持久化

```
对话1: start → mobject → play → (自动保存 state.json)
对话2: start → restored_lines:3 → 场景恢复，继续操作
```
