# manim-web 更新日志

> 版本变更记录

---

## v2.0.1 — 2026-08-08

### 修复

- **静态图形导出缺少 self.add()**：`add_mobject` 现在同时记录 `c = Circle(...)` 和 `self.add(c)`，导出代码可直接运行
- **relaxed 沙箱安全加固**：从白名单移除 `os` 模块（允许 `os.path`），防止通过 `os.system()` 等执行危险操作

---

## v2.0 — 2026-08-07

### 架构重构

- **单进程架构**：移除 TCP 服务器层，`DirectManimSession` 直接操作 manim Scene
- **看门狗机制**：`_ensure_healthy` 自动检测并重建异常会话（最多 3 次）
- **延迟恢复**：`_pending_restore` 等待 WebSocket 连接后再播放恢复动画

### 新增

- 16 个 MCP 工具完整覆盖：会话管理、图形添加、动画播放、代码导出、视频渲染
- 跨对话持久化：`state.json` 保存场景代码，重启后自动恢复
- 三级沙箱：strict / relaxed / full
- WebSocket 二进制帧推送：PNG 帧直接传输，浏览器实时预览
- 守护进程模式：`daemon=true` 后台运行，开机自启动支持

### 工具列表

| 类别 | 工具 |
|------|------|
| 会话 | web_persistent_start, web_persistent_stop, web_persistent_status |
| 图形 | add_mobject, remove_mobject |
| 动画 | play, play_with_targets |
| 导出 | export_code, render_video |
| 查询 | get_mobject_info, get_animation_types, get_available_mobjects |
| 辅助 | reset_scene, get_log |
